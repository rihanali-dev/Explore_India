# 🇮🇳 Explore India

> 🐣 **Milestone Project #1:** This is my very first step into web development! Built entirely with pure HTML5 as a foundation to understand raw page structure before diving into CSS and JavaScript.

A structured, clean, and comprehensive multi-section webpage showcasing India's rich culture, iconic monuments, and travel destinations, built entirely with **pure HTML5**.

---

## 📌 Project Overview

**Explore India** marks the beginning of my coding journey in web technologies. Created as my maiden project, the goal was to master the fundamentals of web architecture, page hierarchy, and semantic elements from scratch without leaning on CSS frameworks or JavaScript libraries.

It captures extensive information—ranging from tourism highlights and cultural heritage to state guides—structured purely with clean, native HTML tags.

---

## ✨ Features

- **Semantic Layout:** Structured with HTML5 standards (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Rich Content Display:** Organized sections for popular states, historical monuments, cuisines, and travel guides.
- **Native Elements:** Implementation of core HTML components including images, descriptive lists, structured data tables, and hyperlinks.
- **Pure Vanilla HTML:** Zero CSS stylesheets, zero frameworks, and zero external scripts—pure markup focus.
- **Blazing Fast:** Loads instantly in any standard web browser with native rendering.

---

* **HTML5** - Page structure, content layout, and semantics
